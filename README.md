# Система планирования маршрутов доставки

## Назначение
Приложение для автоматизации планирования маршрутов доставки заказов. Позволяет создавать заказы, назначать курьеров и оценивать эффективность распределения нагрузки между курьерами.

## Целевая аудитория
- **Менеджеры логистических компаний** — для распределения заказов между курьерами
- **Курьеры** — для получения информации о назначенных заказах
- **Клиенты** — для отслеживания статуса доставки

## Предметная область
**Логистика и управление доставкой** — область, связанная с организацией перевозок грузов от отправителя к получателю. Система охватывает процессы создания заказов, назначения курьеров, расчета эффективности маршрутов и оптимизации доставки.

## Основные сущности
- **Заказ** — содержит информацию о пункте назначения, весе и статусе
- **Курьер** — имеет имя, грузоподъемность и текущий статус
- **Маршрут** — объединяет несколько заказов для одного курьера

## Основные функции
1. `create_order(destination, weight)` — создание нового заказа
2. `assign_courier(order, courier)` — назначение курьера на заказ
3. `calculate_route_efficiency(orders)` — расчет эффективности маршрута
