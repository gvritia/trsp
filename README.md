# Система планирования маршрутов доставки

Консольное приложение для создания заказов, распределения нагрузки между
курьерами и контроля состояния доставки. Проект развивается в рамках
практических работ по дисциплине «Технологии разработки приложений на базе
фреймворков».

## Возможности

- просмотр, создание и поиск заказов;
- сортировка заказов по весу;
- просмотр курьеров и их текущей загрузки;
- проверка доступности курьера с учётом грузоподъёмности;
- назначение курьера на заказ;
- отмена заказа и освобождение занятой грузоподъёмности;
- расчёт процента назначенных заказов;
- автоматическая загрузка и сохранение данных в JSON-файлах;
- обработка некорректного ввода и ошибок файлов.

## Структура проекта

- `main.py` — точка запуска и консольное меню;
- `orders.py` — создание, поиск, фильтрация, сортировка и отмена заказов;
- `couriers.py` — проверка доступности и назначение курьеров;
- `storage.py` — загрузка и сохранение данных в формате JSON;
- `utils.py` — безопасный ввод чисел;
- `data/orders.json` — данные заказов;
- `data/couriers.json` — данные курьеров;
- `tests/` — автоматизированные тесты;
- `requirements.txt` — инструменты тестирования и проверки кода.

Данные представлены списками словарей. Классы и объекты на этапе ПР2 не
используются.

## Требования

- Python 3.10 или новее;
- pytest 8.0 или новее;
- flake8 7.0 или новее.

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
pytest
```

## Проверка качества кода

```bash
flake8
```
