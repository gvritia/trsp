# Название проекта
## Назначение
Краткое описание приложения и задачи, которую оно решает.
## Целевая аудитория
Описание предполагаемых пользователей.
## Предметная область
Краткое описание предметной области.
## Основные сущности
1. `create_order(destination, weight)` — создание нового заказа
2. `assign_courier(order, courier)` — назначение курьера на заказ
3. `calculate_route_efficiency(orders)` — расчет эффективности маршрута
## Основные функции
- **Заказ** — содержит информацию о пункте назначения, весе и статусе
- **Курьер** — имеет имя, грузоподъемность и текущий статус
- **Маршрут** — объединяет несколько заказов для одного курьера
- **Точка** — географическая точка с координатами
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
